# Touchpoint guide

Wheeler's phase 4 applies the identity to every place the brand meets people. For a consumer app
those are below. Each example is written in the brand's voice, names the message it carries, and
says how it looks.

## Store listing (Apple App Store and Google Play)

| Field | Limit | What it does |
|---|---|---|
| App name | 30 (Apple), 30 (Google title) | the name, plus a few words of promise if the name alone doesn't say it |
| Subtitle (Apple) | 30 | the promise in fewest words |
| Promotional text (Apple) | 170 | the current message; changes without a review |
| Keywords (Apple) | 100, comma-separated, no spaces after commas | words people search, not already in the name or subtitle |
| Short description (Google) | 80 | the promise and the main benefit |
| Full description | 4,000 | opens with the promise in 2–3 lines; benefits as short lines; ends with the privacy and health-claims wording |

Screenshots: write each caption (short, one idea, in the voice) and a layout note (what the image
shows, the palette, where the caption sits). The first two carry the promise; most people see no
more. Don't use competitor names in any field.

## Onboarding

3–5 screens. Each: a headline, one line of body, the button text, and a layout note. The first
screen states the promise; one screen sets expectations about data and privacy in plain words;
the last asks for one first action. Tone: welcoming and brief.

## Social

Two example posts for the main channel the person uses (or a general one if none is named): one
that carries the umbrella message, one that proves a supporting message. Caption, image note, and
the voice attributes used. No hashtag stuffing; at most three relevant tags.

## Email

One welcome email: subject (under 50 characters), preview text, a short body with one call to
action, and the sign-off. Tone: warm and specific.

## Website and push notifications (only when chosen)

Website: the hero headline, subhead and call to action. Push: three notifications (a reminder, a
milestone, a re-engagement nudge), each under 100 characters, never guilt-tripping.

## For every piece

- Use only words the brand would use (voice) and one message per piece.
- Proposed text only: the person publishes it.
- Run the health-claims check; soften or flag every claim that needs evidence or sounds medical.
