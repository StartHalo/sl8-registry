# Atlassian: Voice and tone

**Traits (verbatim):** "Bold", "Optimistic", "Practical, with a wink."

**Tone by user state:** Bold: amplify when users feel confident (power users), reduce when confused (new or trial users). Optimistic: more for inspired users, less for uncertain ones. Practical: use when users feel overwhelmed or stressed; "wink" only for moments of success or joy, sparingly.

**A "not" line:** "Delight means little flourishes, not humor or being cheeky."

**Six principles** (e.g. "Inform to build trust", "Encourage people along the path") each tied to a moment in the journey.

**What makes it good (countable):**
- 3 traits, each with an explicit raise/lower rule by user state.
- 6 principles, each tied to a journey moment.
- 1 explicit "X, not Y" boundary on the hardest trait (delight).
- Gap: no before/after rewrites in the text fetched; the page is B2B, so use it for the dial pattern, not the sound.
