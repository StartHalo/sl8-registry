# "Add trust badges to checkout"

- **Hypothesis:** "If payment-security trust badges are added near the pay button, then checkout
  completion will increase, because exit-survey data shows payment-safety concerns."
- **Primary metric:** checkout completion rate · **Guardrails:** average order value, refund rate
- **Baseline:** 3% · **MDE:** 10% relative · **Sample:** about 51,000 per variation · Duration: not given
- **Success criteria:** "Ship if completion improves ≥10% at 95% significance with no guardrail regression."

**What makes it good (countable):** 1 primary metric, 2 guardrails, 3 numbers (baseline, MDE,
sample) and 1 rule set before the test. It lacks the route and the weeks.
