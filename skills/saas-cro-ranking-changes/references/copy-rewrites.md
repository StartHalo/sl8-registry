# Copy rewrites inside the action sheet

When an issue is the wording (a headline that doesn't say what the product does, a button that
doesn't say what happens, a price hidden behind vague text), the action is the rewrite itself,
not "improve the headline".

## Rules

1. **Quote the current text, then give the new text.** "Current: 'Get started'. New: 'Book a
   20-minute demo'." Give 2 options at most when the choice is genuinely open.
2. **Use the customer's words.** When S6 has customer phrases, build the rewrite from them and
   say which note they came from.
3. **The swap test.** Read the rewrite with a competitor's name in place of this product. If it
   still fits, it's too generic: add the specific buyer, outcome or detail that only this product
   can claim.
4. **Say what happens next.** Buttons and form headings name the next step and its cost in time
   ("You'll get a calendar link; the call takes 20 minutes").
5. **No invented claims.** Never write a number, customer count, award, guarantee or result the
   site or the founder didn't supply. If proof would help but none exists, say what proof to
   collect.
6. **No clichés.** Avoid "unlock", "supercharge", "seamless", "all-in-one", "next-level" and
   their kind; they're the first sign of a generic rewrite.
