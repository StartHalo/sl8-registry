# Funnel paths for a B2B micro-SaaS

Most small B2B SaaS sites sell through one of three paths. Name the one the site actually uses
(its main call to action says which), not the one you'd expect.

| Path | What the visitor does | The conversion that matters | Typical key pages |
|---|---|---|---|
| Demo-led | reads the site → requests a demo (form or calendar) → has a call → buys | demo request submitted; then demo held → paid | home, pricing, demo-request form, a features or use-case page |
| Trial-led | reads the site → starts a free trial (with or without a card) → reaches first value → pays | trial started; then trial → paid | home, pricing, sign-up page, the first screen after sign-up if public |
| Freemium | signs up free → uses the free plan → upgrades | sign-up; then free → paid | home, pricing (free vs paid), sign-up |

A site often shows two (for example "Book a demo" and "Start free trial"). Then the founder's main
path is the one the request names, else the one the home page's first call to action points to.

**Conversions are counted per path.** "Demo requests per 100 visits to the pricing page" and
"trials that become paid within 30 days" are different numbers with different benchmarks; never
mix them.

**When the founder gives figures,** write each with its period and source ("12 demo requests in
September, from the CRM"). Rates are computed only from supplied counts. With no figures, every
baseline is `not known`: the review still runs, and the test plan (S10) takes the low-traffic
route.
