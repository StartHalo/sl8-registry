# Customer check (each email, before it's done)

From Jane Portman's Atomic Emails (Userlist, 2026): write from the synopsis, shape a clear CTA
hierarchy (primary, secondary, P.S.), write the subject and preheader, then re-read as the
customer. The questions below are ours; Portman's own list was not recovered in research.

Read the email as one person in the segment, on their phone, between two meetings.

| Check | Fix if not |
|---|---|
| The first line is about them (their situation, problem or goal), not about us | Rewrite the opening |
| The subject alone tells them what's inside and why it's for them | Make it specific; drop cleverness |
| The preheader adds a reason to open, not a repeat of the subject | Rewrite it |
| There is one idea, and one main ask | Cut the second idea; save it as a leftover |
| They get something useful even without clicking | Add the one useful thing (a tip, a number, a step) |
| The ask fits where they are in the sequence (a soft ask early, a plain ask later) | Soften or sharpen the CTA |
| It sounds like the founder wrote it to one person | Remove marketing phrases; use "I" and "you" |
| Every fact has a source (a page opened, or the founder) | Remove the fact |
| Nothing pressures: no fake deadlines, no guilt, no "just checking in" | Remove it |
