# PXL: ordering the changes

PXL (Peep Laja, CXL, 2016; republished by Speero 2021-01-19) asks yes/no questions instead of 1–10
guesses, and weights the noticeable ones double. The original post could not be read (CXL blocks
fetches), and the secondary sources disagree on some weights, so this bot uses the table below and
prints the weights in the review's PXL header. Our choice: Growth Method's weights (2025-07-29),
closest to Speero's "2 or 0 for noticeability", plus Atticus Li's 0–3 ease scale (2026-03-28).

| Question | Points if yes | When to say yes in this job |
|---|---|---|
| Above the fold | 1 | only from a screenshot; without one, 0 (and the review says so) |
| Noticeable in 5 s | 2 | only from a screenshot or a five-second test; without one, 0 |
| Adds or removes an element | 2 | the change adds or removes something (a field, a price, a section), not a restyle or a reword |
| High-traffic page | 1 | the home or pricing page, or the sign-up form |
| User testing | 1 | the founder sent user-test notes that show it |
| Qualitative | 1 | the founder sent customer words (support, reviews, calls) that show it |
| Analytics | 1 | the founder's figures show it |
| Mouse tracking | 1 | the founder sent recordings or heatmaps that show it |
| Ease (0–3) | 3 under an hour · 2 a few hours · 1 a day · 0 more | the founder's own effort, from what the change is |

Total = the sum. Order the ranked changes by total, highest first. Ties: the one nearer the
sign-up comes first.
