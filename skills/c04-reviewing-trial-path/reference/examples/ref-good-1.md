# A sign-up page test: six located changes and one measured result

| Location | Change | Evidence |
|---|---|---|
| Headline | Benefit-focused headline on customer acquisition | variation B: "+16% more people started the signup process" |
| Form layout | Single-column centred form | same test |
| First field | Arrow drawing attention to it | same test |
| Form fields | Removed the password-confirmation field | same test |
| Button | Call to action repeats the main benefit | same test |
| Proof | Sample user profiles and peer language | same test |

**What makes it good (countable):** 6 changes, each at a named place on the page; 1 measured
outcome with its measure (visitors who started sign-up). It has no ranking or priority.
